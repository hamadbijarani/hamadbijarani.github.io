Estimation assumptions & limitations

Representative dense, non-GQA transformers (1.1B: 24 layers, 8.0B: 32 layers, hidden 4096, feed-forward 14336, and so on). Not named checkpoints. Q/V: 4Ldr; attention: 8Ldr; all linear: Lr[8d + 3(d + f)]. Embeddings and output head are excluded.

LoRA adapters remain mixed precision. Memory uses frozen weights × 1.2 for overhead, 16 bytes per trainable parameter for Adam-style training, and a fixed 2 GiB activation allowance. Full fine-tuning uses 16 bytes per backbone parameter + 2 GiB. 1 GiB = 2³⁰ bytes.

These are planning estimates, not measured performance. Sequence length, batch size, checkpointing, grouped-query attention, kernels, and quantization metadata change actual requirements. Parameter reduction is not VRAM reduction.
