# Hamadullah Bijarani — Academic Portfolio

Static site for GitHub Pages. No build step.

Files: `index.html` (page, styles and scripts), `assets/Hamadullah-Bijarani-CV.pdf`, `assets/hamadullah-bijarani.jpg`.

Deploy: push these to a repo named `hamadbijarani.github.io` (or any repo), then Settings → Pages → Deploy from branch → `main` / root.
